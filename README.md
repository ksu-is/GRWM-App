# GRWM-App
GRWM is a Python-based fashion application that helps users organize their wardrobes, put together outfits, and plan what to wear. The idea behind this project is to make getting dressed easier by allowing users to keep track of the clothes they own and create outfit combinations using those items.
Project goals would be: allow users to add and organize clothing items in a digital wardrobe, help users create outfits using clothes they already own, Allow users to plan outfits for different days or occasions, Create a simple and easy-to-use interface.
